# 中文个人主页

简洁、适配手机的个人主页，包含自我介绍、作品展示和联系方式。所有资料均为示例，不需要安装软件包或注册服务。

## 最简单的预览方法

1. 将仓库文件下载到电脑并解压。
2. 双击 `index.html`，浏览器就会打开网页。请让 `style.css` 和它放在同一个文件夹里。

## 在开发环境中预览

在 `/workspace/my-first-site` 目录运行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

通过开发工具的端口预览功能打开 8000 端口。在自己的电脑运行时，也可在浏览器输入 `http://localhost:8000`。按 `Ctrl+C` 停止服务。如果云环境没有端口预览入口，请使用上面的下载预览方法。

## 换成自己的资料

- `index.html`：修改姓名、自我介绍、作品说明和邮箱。邮箱需要同时修改 `mailto:` 后的地址与页面显示的地址。
- `style.css`：控制颜色、字体和手机排版。
- 三幅作品封面用 CSS 绘制，不需要图片文件。它们是概念示例，没有作品详情页。

页面无需外部字体、图片、脚本或网络服务。邮箱链接会调用设备上的邮件程序；示例邮箱 `hello@example.com` 不用于实际联系。
